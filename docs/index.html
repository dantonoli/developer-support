A cleaner clipboard for macOS

PlainClip lives in your menu bar and cleans the text you copy — so pasting stays plain and predictable, in whatever app you land in.

macOS 14 or later · no accounts · no network access

What it cleans

Every rule below is a separate switch. Turn off anything that does not suit you.

Rich text, flattened

Copies from the web, Word and Outlook arrive as plain text instead of carrying fonts, colours and table markup with them.

Invisible characters

Zero-width spaces, soft hyphens and byte-order marks that web and chat copies smuggle along are removed.

Hidden markers

Variation selectors, Unicode tag characters and direction controls that some apps and tools embed in text are stripped out.

Tracking parameters

utm_* and friends are dropped, and AMP or redirect links are unwrapped back to the real destination.

Smart quotes and dashes

Curly quotes and em dashes become their plain equivalents, so code and config files paste correctly.

PDF line breaks

Lines broken by a PDF's column width are rejoined into real paragraphs.

List structure

Bullet nesting survives the trip from a formatted document into a plain-text field.

Per-app exclusions

Name the apps where formatting matters and PlainClip leaves their clipboard alone.

It tells you what it changed

The status line names only the rules that actually altered the text — never the ones that did nothing.

PlainClip can also inspect a clipboard on request and report the invisible characters it finds. When it finds none, it says so plainly, and adds that watermarks woven into the word choice of generated text cannot be detected this way. That wording is deliberate: PlainClip removes character-level markers only, and silence should never be read as proof that a piece of text is unmarked.

Nothing leaves your Mac

Your clipboard is among the most sensitive things on your computer. PlainClip treats it that way.

  • No network entitlement, and no network connections.
  • No accounts, no sign-in, no analytics, no telemetry.
  • Clipboard contents are read and rewritten locally, and are never transmitted.
  • Password-manager copies, which macOS marks as concealed, are skipped.

The optional copy fingerprint is off by default and manual only. When enabled, it embeds an invisible marker — the copy time and a short label you choose — into text you copy, so a paste can be traced back to the copy event. It uses a random per-install identifier that is never derived from any hardware or device ID, it is never transmitted, and “Clean clipboard now” removes it. Full detail is in the privacy policy.
